# forger-multichar
Framework-agnostic cinematic multicharacter selector for QBCore, Qbox &amp; ESX Legacy. Live 3D character showcase with poses, camera zoom, weather/time &amp; filters, plus a spawn selector, per-player slot limits (identifier/ace/Discord overrides) and pluggable clothing support (illenium, fivem-appearance, skinchanger, qb-clothing). Requires oxmysql.
